# Documentação do projeto

Esta pasta reúne os artefatos básicos de análise e projeto do **Meu Consumo**.

- [Levantamento de requisitos](requisitos.md): escopo, atores, requisitos,
  regras de negócio e critérios de aceite.
- [Modelo de dados e DER](modelo-de-dados.md): estrutura atual em JSON,
  dicionário de dados e proposta para uma futura migração relacional.
- [Modelagem UML](uml.md): casos de uso, classes da arquitetura e sequência do
  registro de uma leitura.
- [`diagramas/`](diagramas/): fontes Mermaid e versões SVG dos diagramas.

Atualize estes documentos quando uma alteração mudar comportamento, dados,
regras de negócio ou responsabilidades entre módulos.
